# Dwarf Forge 架构

游戏以第一人称 Three.js 工坊呈現锻造、交易与巨龙税收。原创几何、SVG 材质和 Web Audio 声音由代码生成；桌面键鼠与手机摇杆、滑动视角共用同一规则模型。

`simulation.js` 与 `rules.js` 管理可序列化状态、锻造结果、遗物票数、剑币、商人库存、21 天合约与回溯。所有经济动作先验证条件，失败时不花费资源。`save-slots.js` 保存三个本地合约，共享图鉴与解锁，兼容已有存档字段。

`main.js` 连接模型、DOM 菜单、音频与场景回调。`workshop.js` 负责相机、物品命中、灯光和渲染；剑型、物理、全身阴影、交互动画与票数看板有独立模块。拾取与加热先播放过渡，锤击在接触时提交一次结果。菜单、导览、页面失焦时暂停输入与狂热计时。

界面以 DOM 提供清晰文本；场景牌面由 SVG 生成，并按贴图宽高保持比例。手机可以直接交互，也可用设施菜单前往工位。原作参考与推定边界见 [规则证据](rules-evidence.md)，交互反馈见 [工坊反馈](workshop-feedback.md)。

验证以 Node 原生测试覆盖经济、存档与交互边界，生产构建验证模块组合，浏览器检查实际 WebGL、手机布局和链接。云端 CI 执行安装、测试和构建；部署单独进行。
