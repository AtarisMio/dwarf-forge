# 手机体验

2026-10-12 更新。保留第一人称、剑的进化、经济规则和原有存档格式。

## 操作与界面

- 粗指针设备或窗口宽度不超过 760px 使用触屏布局。左侧摇杆按偏移量移动，松手归零；画面滑动观察，轻点目标交互。摇杆与观察分别持有自己的 pointerId，可以同时使用两根手指。
- 右侧「交互」复用 E 的场景动作，「放下剑」复用右键动作。「设施」打开暂停的设施菜单，隐藏未到访的幽灵商人。打开菜单、设施聚焦、失焦、取消触点或切到后台都会清空移动手势。
- 铁砧的触屏点击在抬手时确认；滑动不会误敲。桌面鼠标操作与键盘快捷键保留。锻造间隔、概率、狂热时长和每次挥锤数量不因设备改变。
- 竖屏锻造面板位于下方，横屏使用底部两列控制条，让剑保持可见。剑名、等级、价值和概率使用 DOM 显示；概率、消耗品与回溯默认收起。短横屏只使用面板的一个滚动容器，底部物品按钮可以完整滚入视野。
- 手机可打开大字商品说明领取赠礼／购买遗物，加热后可直接前往铁砧。开场提示和操作帮助使用触屏动作说明。菜单可滚动，使用动态视口高度和刘海／底部手势安全区；没有禁用页面缩放。

## 渲染预算

首次创建场景时按粗指针决定渲染预算。手机像素比最高 1.5，关闭 MSAA，阴影贴图 512、PCF；纹理各向异性上限 8。桌面保留像素比最高 2、MSAA、1024 阴影、PCFSoft 和各向异性上限 16。几何细节、SVG 面板和模拟时钟不降级；此设置减少像素与阴影工作量，不等于已经测得真机帧率提升。

## 验证

89 项 Node 测试通过，包含摇杆模拟幅度／径向限幅、双指独立输入、暂停／取消／隐藏释放、触屏铁砧滑动与轻点区分、指针捕获兼容及渲染预算。生产构建与 diff 检查通过。

浏览器检查 390×844、360×740、360×500、844×390 与 568×320，锻造按钮和设施入口均在视口内，互不覆盖。短竖屏保留单列锻造面板；横屏仍显示龙怒标记。实际走通导览、赠礼三选一、选剑、加热、进入铁砧、挥锤、取剑、进贡、欠税确认、暂停和三个存档菜单。小屏横屏展开消耗品后，滚动可看到完整使用／回溯按钮。桌面继续存档、键鼠帮助和默认展开的消耗品面板正常，触控摇杆隐藏。

测试使用 Chromium 的手机尺寸、粗指针模拟与浏览器原生指针操作。当前浏览器不提供 Input.dispatchTouchEvent；双指触点及取消边界由输入模块回归测试验证，没有声称在实体 Android／iOS 上完成多指、刘海或低端设备性能测试。没有清空或覆盖生产存档来制造测试进度。
