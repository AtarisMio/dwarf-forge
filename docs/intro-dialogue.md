# 新合约开场导览

参考：[寅子合集《ForgeTax》P1](https://www.bilibili.com/video/BV16yHX6zEJV/?p=1)。2026-10-12 通过网页播放器核对了开场教学，约 00:30–01:20：底部逐句字幕，镜头依次展示炉火、铁砧、入神充能、抽签表、贡台、铃、备用剑架、投剑购买台；随后进入免费三选一。

本版用原创中文概括教学，适配网页操作：十段巨龙对话，底部字幕、对应设施镜头，继续／上一句／跳过。字幕为 DOM 字体，没有把中文栅格化进场景贴图。内容包括加热一次、强化的五种结果、同剑十锤蓄满后下一锤入神、敲铃才收走贡品、三次欠贡失败、备用剑架、剑币和金币用途以及赠礼规则。不会播放原视频音频或复制逐字字幕。

触发：开始全新合约或选择空存档；已有存档继续不会重播。跳过和正常读完都进入首日遗物购买台。引导的页码独立于游戏状态，不改变存档格式、经济数值或物品。

引导期间暂停物理、游戏计时、移动和设施交互，只让镜头平滑移动。按钮可用 Tab 操作；E／右箭头继续，左箭头上一句，Enter／空格激活焦点按钮，Esc 跳过。切换窗口不额外弹出暂停菜单。

实现：`src/intro-dialogue.ts` 管理内容和页码；`src/main.ts` 接入新合约、输入与计时；`src/workshop.ts` 提供暂停时的导览镜头；`index.html` 和 `src/style.css` 提供清晰字幕。

验证：导航、跳过、重启、空存档／读档分支的单元测试；浏览器核对开场、镜头、键盘与按钮、完成和跳过进入赠礼、加载进度不重播。发布到现有 Cloudflare Worker 后检查 HTTPS 和静态资源，并保存界面截图。
