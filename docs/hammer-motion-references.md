# 单手锤击参考与证据边界

核对日期：2026-10-13。用于调整第一人称挥锤的握柄、抬落与回程。

优先看下面三个原发布者来源。前两个已下载公开原视频，用 FFmpeg 连续抽帧并实际查看；第三个由主线程打开播放器并定位章节。抽帧可以确认姿势变化和动作顺序，不能单凭这些图测出关节精确角度、握力或被动回弹的贡献。

## 1. 巴西现场：短片中的连续单手锤击

- 原发布者：Eugenio Hansen, OFS。2015-09-13 拍摄；[原文件页](https://commons.wikimedia.org/wiki/File:Acampamento_Farroupilha,_Parque_da_Harmonia,_Porto_Alegre,_Brasil_2015_17.webm)标明作者本人拍摄与上传，片长 31.689 秒。
- [公开视频直链](https://upload.wikimedia.org/wikipedia/commons/a/ac/Acampamento_Farroupilha%2C_Parque_da_Harmonia%2C_Porto_Alegre%2C_Brasil_2015_17.webm)。无需 YouTube 播放器。
- **已查看区间：00:01–00:03**，8 帧/秒，按顺序查看 16 帧。适合先看整个 32 秒短片，再重复这一段。

画面可确认：右手持锤，左手用钳固定发亮的工件。抬锤时，握柄手与前臂一起上移，肘的弯曲随之改变；不是把手固定在一个空间点，仅绕腕旋转锤子。落下时锤头到达铁砧上的工件，握柄手仍在工作面上方。随后锤头再次抬起，连续帧里没有长时间压住工件的姿态。

这段是侧前方视角，能比较锤头与手的相对高度。光线较暗，右侧旁观者也遮住部分画面；**不能确认每根手指的握法、拇指位置、精确接触帧或回程有多少来自自然弹起**。

## 2. 芬兰博物馆：较完整的手臂与工作台关系

- 原发布机构：Sounds of Changes / Työväenmuseo Werstas；声、照片与视频作者 Antti Makkonen，2018-07-15 在 Möhkön Ruukki 拍摄。[原发布页](https://www.soundsofchanges.eu/sound/3083/)明确说明记录加热、锤砧塑形和风箱过程。
- [公开视频直链](https://upload.wikimedia.org/wikipedia/commons/b/b3/Blacksmith_Working_at_M%C3%B6hk%C3%B6n_Ruukki.webm)，视频约 3:57；[对应文件及来源记录](https://commons.wikimedia.org/wiki/File:Blacksmith_Working_at_M%C3%B6hk%C3%B6n_Ruukki.webm)。这是原发布视频的公开副本，不依赖 YouTube 登录。
- **已查看锤击区间：02:42–02:59**；其中 **02:43–02:45** 用 12 帧/秒连续查看 24 帧。此前较长一段在炉前操作，研究挥锤可直接跳到上述区间。

画面可确认：一手固定工件、一手单独挥锤。握柄手在接触附近仍高于锤面；手掌、腕、前臂和肘在抬落过程中共同改变位置。锤头往复移动，接触附近之后再次抬起；前臂的方向跟着手的位置变化，不能把整条前臂视作与锤子完全同角度旋转的直杆。较宽的画面同时保留身体、铁砧与手臂，适合核对手是否不合理地下穿工作面。

**边界：**没有逐帧识别手指的夹持压力，也没有音画同步测量；不从这段帧序列推出统一的挥锤周期、接触停留毫秒数或手腕旋转角度。拍摄者的说明能确认记录的工序，但具体动作结论来自上面的实际帧序列。

## 3. 绿川千代：原作者锻打入门教学

- 原作者：绿川千代，2024-01-01 发布。[《从零开始的打铁教学【2】——我流锻打派入门》](https://www.bilibili.com/video/BV1pC4y1i7pf/)，约 25:31。[原作者合集条目与说明](https://www.bilibili.com/list/1786813?bvid=BV1pC4y1i7pf&oid=793111838)说明由作者撰写较长的锻打教学文案，不是海外视频搬运。
- **主线程已确认观看入口：01:30–04:25，「发力方式」章节。**这是播放器实际定位结果，不是依据标题猜测的时间戳。仅播放了开头预览；跳到章节后播放器要求登录，未据此推定整段动作。
- 适合补核：握柄手的位置、抬锤由哪些关节配合、落下与回程如何衔接。

**边界：**本研究 lane 只独立核对了作者、原投稿链接和作者说明，没有独立观看或抽取该段视频帧；因此这里不写具体的握法、腕角或回弹结论。上述待核项目不是已经观察到的事实。

## 原作者文字提供的额外约束

Crossed Heart Forge 的[《You Need A Japanese Swordsmith’s Hammer》](https://islandblacksmith.ca/2013/04/why-you-need-a-japanese-swordsmiths-hammer/)说明：锤面与柄的相对角度需要配合铁砧高度；角度或头部长度过大，会使击打时手的位置过低，反之会使肩部抬高。作者也说明较小的锤面适合窄刃目标，以免刀刃变薄时误击铁砧。

这些是作者文字确认的设计关系，**不是已观看该站视频后测得的数据**。它们支持同时核对手的位置与锤面接触，而不能用“锤面碰到了工件”单独判定姿势自然。
